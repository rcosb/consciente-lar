# Conecta-Lar (Portal ConscienteLar)

## Descrição

O Portal ConscienteLar é uma plataforma educacional que conecta profissionais voluntários (psicólogos, pedagogos, advogados e outros especialistas) a pais adotantes e instituições de acolhimento. A plataforma oferece cursos gratuitos sobre os desafios reais da adoção e do acolhimento institucional, organizados em categorias como Pré-adoção, Pós-adoção e Acolhimento Institucional.

Profissionais podem se cadastrar como voluntários para criar e compartilhar cursos, enquanto famílias adotantes e instituições acessam o conteúdo gratuitamente para capacitação e suporte na jornada da adoção.

## Funcionalidades

- Cadastro de voluntários (profissionais) e alunos (pais/instituições)
- Criação e gerenciamento de cursos por voluntários
- Catálogo de cursos organizados por categorias
- Dashboard personalizado para voluntários e alunos
- Sistema de autenticação com perfis diferenciados


## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/conecta-lar.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd conecta-lar
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```

## Uso

1. Execute a aplicação:
   ```bash
   npm run dev
   ```
2. Acesse no navegador:
   ```
   http://localhost:5009
   ```
